# WB Бренды 2.0 — хаб прототипов

Хаб с четырьмя концептами развития раздела «Бренды» + дополнительный макет концепт-стора.

## Структура

- `index.html` — хаб (стартовая страница)
- `Pavilion.dc.html` — A · Павильон
- `Concept.dc.html` — B · Концепт-стор
- `Outlet.dc.html` — C · Аутлет
- `Hybrid.dc.html` — D · Гибрид
- `Concept-END.dc.html` — концепт-стор, ещё макет
- `support.js` — рантайм (обязателен, лежит рядом)

## Как опубликовать на GitHub Pages

1. Загрузите все файлы в корень репозитория (Add file → Upload files)
2. Settings → Pages → Source: Deploy from a branch → main → Save
3. Через минуту хаб будет доступен по ссылке вида `https://<username>.github.io/<repo>/`
